# OpenMAIC 生产集成测试计划

## 1. 测试目标与验收范围

本测试计划用于 OpenMAIC 集成课程平台上线前验收，验证 AI 创作、资源入库、课件挂载、课堂播放、权限隔离、失败恢复和国产化部署约束是否满足生产要求。

### 1.1 验收范围

- 教师端 AI 创作工坊：PPTX、讲稿、小游戏、项目任务、实操对话、TTS 音频生成。
- 管理端 AI 服务治理：OpenMAIC、大模型、TTS、OnlyOffice/WPS/PowerPoint 兼容状态与配置展示。
- 资源流转闭环：生成任务 → 草稿 → 教师确认/管理员审核 → 平台资源库 → 课件节点挂载 → 教师课堂端/学生端使用。
- PPTX 导出与预览：导出文件可被 WPS、Microsoft PowerPoint、OnlyOffice 正常打开、预览和播放。
- miniapps 安全运行：AI 生成小游戏进入平台 miniapp 包装与 iframe 沙箱，不绕过平台权限和事件协议。
- TTS 能力：讲稿转音频、音频入库、课件页绑定、失败重试和超时处理。
- 隐藏功能验证：OpenMAIC 的课堂讨论、圆桌讨论、多智能体课堂辩论、学生端实时 AI 讨论不对教师/学生暴露。
- 国内源与无 Docker 约束：生产部署与测试流程不依赖 Docker，不依赖不可访问的海外包源或外部服务。

### 1.2 不在本轮验收范围

- 学生直接调用 OpenMAIC 生成内容。
- OpenMAIC 原生后台完整功能验收。
- 面向学生的实时 AI 讨论、roundtable、多智能体辩论。
- 第三方公网模型服务的 SLA 承诺；只验收课程平台代理、降级和错误提示。

## 2. 测试环境约束

### 2.1 部署约束

- 课程平台是唯一公网业务入口，只开放 `80/443`。
- OpenMAIC、TTS、大模型代理、OnlyOffice 回调等内部服务默认只监听 `127.0.0.1` 或内网地址。
- 不使用 Docker 或 docker-compose 作为必需运行方式；服务应通过 systemd、进程管理脚本或现有部署方式运行。
- 安装依赖优先使用国内源：npm/pnpm、pip、apt、模型文件镜像或内网制品库。
- 测试人员不得为了通过测试临时开放 OpenMAIC/TTS/模型端口到公网。

### 2.2 数据约束

- 使用测试学校、测试课程、测试教师、测试学生和测试班级。
- AI 生成内容必须先进入草稿或待审核状态，不允许直接发布到学生端。
- 测试资源应带有明确标识，例如 `OpenMAIC生产验收`，便于清理和审计。
- 不使用真实学生隐私数据作为大模型输入。

## 4. OpenMAIC 集成验收流程

| 编号 | 测试项 | 操作 | 预期结果 |
|---|---|---|---|
| INT-01 | 服务健康检查 | 管理员打开 AI 服务治理页 | OpenMAIC、TTS、大模型、OnlyOffice 状态清晰展示，异常服务有错误原因 |
| INT-02 | 教师入口展示 | 授权教师打开 AI 创作工坊 | 只展示 PPT、讲稿、小游戏、项目协助、实操对话等允许入口 |
| INT-03 | 任务创建 | 教师选择课程、课时、教学目标创建生成任务 | 返回任务 ID，状态进入排队/运行中，不阻塞页面 |
| INT-04 | 结果草稿 | 等待任务完成 | 生成内容进入草稿，包含来源任务、创建者、课程上下文、时间戳 |
| INT-05 | 教师确认 | 教师编辑并保存草稿 | 保存为平台资源或 miniapp 草稿，不直接面向学生发布 |
| INT-06 | 管理审核 | 管理员审核需发布资源 | 审核通过后才可挂载到正式课件或学生可见资源 |
| INT-07 | 课件挂载 | 教师将资源挂入课件节点 | 教师课堂端可打开，学生端只看到已发布内容 |
| INT-08 | 审计追踪 | 查看任务与资源记录 | 能追踪生成任务、模型、操作者、资源版本和发布状态 |

## 5. PPTX 导出兼容手工清单

每个样例 PPTX 至少覆盖：标题页、目录页、图文页、表格页、流程图页、测验页、互动提示页、讲稿备注页、含中文字体页、含图片页、含视频占位页。

### 5.1 WPS Office 清单

- 文件可打开，无损坏修复提示。
- 中文字体显示正常，未出现大面积乱码、方块字或错位。
- 页面比例、背景色、图片裁切、文本框位置与平台预览基本一致。
- 表格边框、单元格填充、合并单元格显示正常。
- 备注区或讲稿内容可查看，不影响幻灯片放映。
- 动画或转场不支持时有合理降级，不影响主体内容。
- 嵌入图片能离线显示，不依赖平台登录态。
- 含视频页至少显示封面、标题和播放说明；若为链接视频，链接可点击且权限受控。
- 保存后再次打开，不丢页、不丢图、不破坏版式。

### 5.2 Microsoft PowerPoint 清单

- Windows PowerPoint 可打开，无兼容性修复警告。
- macOS PowerPoint 抽测可打开，字体替换可接受且不遮挡主体内容。
- 放映模式下页面顺序、比例、图层顺序正确。
- SmartArt/形状/箭头/流程图显示不变形。
- 图片透明度、圆角、裁切和阴影效果可接受。
- 备注页可查看并打印。
- 文件属性不包含敏感 token、内部 URL、绝对服务器路径。
- 导出为 PDF 后主体内容完整。

### 5.3 OnlyOffice 清单

- 平台内 OnlyOffice 预览可打开，不出现转换失败。
- 在线编辑后保存，版本能回写平台资源库。
- 多页切换、缩略图、备注区显示稳定。
- OnlyOffice 转换结果与下载 PPTX 主要版式一致。
- 并发打开同一 PPTX 时不会覆盖他人版本。
- OnlyOffice 回调失败时，平台保留原始文件并提示重试。

## 6. AI 能力测试矩阵

| 能力 | 输入覆盖 | 成功验收 | 失败/边界验收 |
|---|---|---|---|
| 图片生成/处理 | 课程主题、年龄段、风格、尺寸、版权提示 | 图片入库，缩略图可见，可挂课件，来源可追踪 | 提示词违规、生成超时、图片过大、格式不支持时进入失败状态并可重试 |
| 视频生成/处理 | 视频链接、封面、脚本、时长、字幕 | 视频资源或视频占位页可挂载，播放权限受控 | 外链不可达、转码失败、超大小、无封面时有清晰提示 |
| TTS | 讲稿文本、音色、语速、格式、批量页 | 音频入库，可试听，可绑定 PPT 页/小游戏旁白 | 空文本、超长文本、服务不可用、单页失败不影响其他页 |
| 大模型文本 | 课程上下文、课标、年级、教学目标 | 生成内容结构化，包含可编辑草稿和来源任务 | 模型限流、JSON 格式错误、内容安全拒绝时不写入脏数据 |
| 小游戏 | 玩法、知识点、题目数、素材约束 | 生成 miniapp 草稿，通过安全校验，可在 iframe 沙箱运行并回传事件 | 危险脚本、外链、超包体、事件协议缺失时禁止发布 |
| 讲稿 | 按课时、按 PPT 页、按活动环节 | 逐页讲稿可编辑、版本保存、可用于 TTS | 页数不匹配、重复生成、部分失败时保留可用页并标记异常 |
| 项目任务 | PBL 目标、分组方式、评价量规、产出物 | 生成项目说明、步骤、检查点、评价量规，可转课件节点 | 任务过大、评价标准缺失、年级不匹配时给出修改建议 |
| 质量检查 | 内容完整性、错别字、敏感词、版权、课标匹配 | 输出问题清单、风险级别、修复建议，可回写草稿 | 检查服务失败不阻断资源保存，但阻断自动发布 |

## 7. 超时、重试与失败模式

| 编号 | 失败模式 | 注入方式 | 预期行为 |
|---|---|---|---|
| FAIL-01 | OpenMAIC 不可用 | 停止 OpenMAIC 或配置错误地址 | 健康检查异常，生成按钮禁用或任务立即失败，提示联系管理员 |
| FAIL-02 | 大模型超时 | 模拟接口超过平台超时阈值 | 任务进入超时失败，不重复提交脏任务，可手动重试 |
| FAIL-03 | TTS 单页失败 | 让某一页文本触发失败 | 其他页音频保留，失败页标记可重试 |
| FAIL-04 | PPTX 导出失败 | 模拟导出进程异常 | 不生成损坏文件，草稿仍可编辑，错误日志可查 |
| FAIL-05 | OnlyOffice 回调失败 | 阻断回调或返回 500 | 原版本不被覆盖，页面提示保存失败并可重试 |
| FAIL-06 | miniapp 安全校验失败 | 生成含外链脚本或危险 API 的 HTML | 禁止发布，显示安全检查问题，不进入学生端 |
| FAIL-07 | 任务队列积压 | 并发提交多任务 | 展示排队状态、预计等待或友好提示，不导致页面假死 |
| FAIL-08 | 资源入库失败 | 模拟存储目录不可写或 DB 写入失败 | 任务失败且可追踪，不出现文件有而数据库无的孤儿发布状态 |
| FAIL-09 | 权限过期 | 任务运行中教师被移除权限 | 后续保存/发布被拒绝，已生成草稿按管理员策略处理 |
| FAIL-10 | 浏览器关闭 | 创建任务后关闭页面再回来 | 能通过任务列表恢复状态，不重复扣配额 |

### 7.1 超时建议

- 健康检查：3-5 秒内返回。
- 普通文本生成：60-120 秒内完成或进入后台任务。
- PPTX/小游戏生成：超过 120 秒必须异步化并显示任务状态。
- 批量 TTS：按页异步处理，单页超时不阻断整批任务。
- 文件转换/OnlyOffice：超过平台阈值时提示后台处理中或保存失败，不让用户误以为已成功。

## 8. 隐藏课堂讨论类功能验证

| 编号 | 验证点 | 操作 | 预期结果 |
|---|---|---|---|
| HIDE-01 | 教师端导航 | 搜索 AI 创作工坊、课堂端、备课页 | 不出现课堂讨论、圆桌讨论、多智能体辩论入口 |
| HIDE-02 | 学生端导航 | 学生登录并进入课程/课堂 | 不出现实时 AI 讨论或 OpenMAIC 聊天入口 |
| HIDE-03 | 直接 URL | 尝试访问可能的 discussion/roundtable 路径 | 返回 404、无权限或重定向，不展示功能页面 |
| HIDE-04 | API 枚举 | 调用 `/api/openmaic/*` 中疑似 discussion 接口 | 未授权或未实现，不代理到 OpenMAIC 讨论能力 |
| HIDE-05 | 数据导入 | 导入含 `multiAgent`、`discussion` 的 OpenMAIC 场景 | 平台忽略、清空或标记不支持，不在课件中渲染讨论组件 |
| HIDE-06 | 前端文案 | 全站搜索课堂讨论类关键字 | 仅允许文档/内部说明出现，生产 UI 不展示入口 |
| HIDE-07 | 权限绕过 | 管理员给教师开启全部 AI capability | 仍不展示隐藏功能，隐藏不依赖单一前端开关 |

## 9. 安全与合规检查

- 所有 AI API 必须经过登录态和角色鉴权。
- 教师只能使用本人学校、班级、课程或被授权课程上下文。
- 模型请求日志不得保存明文密码、token、Cookie、学生隐私数据。
- AI 生成资源必须标记来源和生成时间，便于审核与追责。
- miniapp HTML 禁止任意外链脚本、危险协议、顶层跳转、访问父页面敏感对象。
- PPTX 文件属性和备注不得包含内部服务地址、系统提示词或密钥。
- TTS、图片、视频等生成结果应进行文件类型、大小、扩展名和 MIME 校验。
- 管理端配置变更应记录操作者、时间、旧值摘要和新值摘要。

## 10. 国内源与无 Docker 验证

| 编号 | 测试项 | 操作 | 预期结果 |
|---|---|---|---|
| CN-01 | 依赖安装 | 使用配置好的国内 npm/pnpm/pip/apt 源安装依赖 | 不依赖 Docker，不访问不可用海外源即可完成 |
| CN-02 | 服务启动 | 使用 systemd 或现有脚本启动平台、OpenMAIC、TTS | 重启后服务自动恢复，状态可检查 |
| CN-03 | 模型文件 | 在无公网或仅国内镜像环境下加载模型 | 模型路径可配置，缺失时有明确错误 |
| CN-04 | 前端资源 | 断开海外 CDN 后访问页面 | 字体、图标、脚本、样式不依赖海外 CDN |
| CN-05 | 文件转换 | OnlyOffice/WPS/PowerPoint 手工验证 | 不要求 Docker 版 OnlyOffice 才能完成核心验收 |
| CN-06 | 部署文档 | 检查上线命令 | 文档和脚本不把 Docker 作为唯一生产路径 |

## 11. 上线准入标准

- P0：权限绕过、学生可调用 AI、内部端口公网暴露、miniapp 危险脚本发布、PPTX 大面积无法打开，任一存在即禁止上线。
- P1：核心生成链路失败、资源入库不一致、OnlyOffice 回写覆盖、TTS 批量不可恢复，必须修复后上线。
- P2：个别版式偏差、非关键文案问题、兼容性轻微降级，可记录并排期修复。
- 所有 P0/P1 问题关闭后，由产品、测试、开发、运维共同确认上线。
